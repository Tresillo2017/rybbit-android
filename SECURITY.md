# Security Policy

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Report them privately through
[GitHub Security Advisories](https://github.com/Tresillo2017/rybbit-android/security/advisories/new).

Include the affected version, steps to reproduce, and the impact. You should get a reply within a few
days.

## Scope

In scope:
- how the app stores credentials (Keystore encryption);
- credentials leaking, for example through logs, redirects, backups or other apps;
- TLS and network-security configuration issues;
- anything that sends data somewhere other than the server the user configured.

Vulnerabilities in the Rybbit server itself belong to the
[Rybbit project](https://github.com/rybbit-io/rybbit/security).

## Supported versions

Only the latest release gets security fixes.
